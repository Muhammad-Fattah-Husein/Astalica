Deskripsi Proyek

Astalica adalah platform web profil perusahaan terpadu dan sistem reservasi busana Muslim adibusana (haute couture). Proyek ini memadukan visual adibusana beresolusi tinggi dengan sistem backend tangguh: mulai dari interaksi pemilihan tekstur kain sutra, warta tren modest fashion dinamis, hingga pemesanan pesanan kustom bersistem kode tiket unik dan verifikasi pembayaran QRIS otomatis.

Tech-Stack Utama

Next.js 14 App Router TypeScript 5 Tailwind CSS 3.4 Supabase PostgreSQL Google Sheets API Proxy Jose (JWT) Bcryptjs Framer Motion

Arsitektur Keamanan

✦ Cookie HttpOnly: Token autentikasi aman dari serangan XSS.
✦ Role-Based Access: Proteksi halaman admin dan akses data klien terisolasi.

Teknologi & Fitur Unggulan

✦ React Server Components (RSC): Render instan, SEO teroptimasi, dan zero layout shift.
✦ Interactive Fabric Experience: Modul interaktif tekstur kain Mulberry Silk & Voile de Luxe.
✦ QRIS Payment Simulation: Barcode standar nasional, kode tiket AST-YYYYMMDD-XXXX, dan integrasi WhatsApp Concierge.
✦ Full Admin Dashboard: Pengelolaan pesanan masuk, moderasi artikel berita, dan manajemen akun staf.

Dual-Backend Database Architecture

Sistem dirancang adaptif dengan dukungan Supabase Cloud PostgreSQL berfitur RLS (Row Level Security) serta failover Google Spreadsheet API via Google Apps Script. Struktur terisolasi di sisi server (Server-side API Proxy) sehingga kredensial database tidak pernah bocor ke sisi klien.
